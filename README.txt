深圳人生 · 本地预览

1. 在终端进入本文件夹（dist/）
2. 运行：python3 -m http.server 8080
3. 浏览器打开：http://localhost:8080

也可以直接双击 index.html 打开（离线缓存功能仅在 localhost/https 下启用，游戏本身不受影响）。
虚构娱乐作品，城市币不可提现。

文件：index.html（游戏本体，单文件离线）、manifest.webmanifest + sw.js（本地服务器下可添加到主屏）、favicon.png / icon-192.png / icon-512.png（图标）、og.png（分享预览图 1200x630）。
注意：og:image 目前是相对路径；正式托管后需改成绝对网址，社交平台才会显示预览图。
